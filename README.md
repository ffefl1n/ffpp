# ffpp — Минималистичный VLESS & Hysteria клиент для iOS (17+)

Минималистичный, быстрый и энергоэффективный VPN-клиент для iOS со встроенным ядром **sing-box 1.11 (Libbox)** в системном туннеле (`PacketTunnelProvider`), полноценной эмуляцией клиента **Happ** (обход проверки `User-Agent` и привязка постоянного `X-Hwid`) и тройной системой защиты сохранности подписок.

---

## Что нового в v1.0.3

* **Исправлен обрыв туннеля при старте**: Восстановлено прямое получение TUN сокет-дескриптора через KVC перед внешним сканером.
* **Надежная PTP-маршрутизация**: Удален конфликтный шлюз 127.0.0.1, туннель маршрутизируется через 172.19.0.2.
* **Экранная диагностика ошибок**: Если туннель завершился с ошибкой, сообщение из расширения отображается в Dashboard.
* **Удалена инструкция по GBox**: Меню настроек очищено от устаревшего гайда.

---

## Что нового в предыдущих версиях

* **v1.0.1 / v1.0.2**:
* **Встроенное ядро sing-box (Libbox 1.11.11)**: Полноценный сетевой стек `mixed` / TUN в расширении NetworkExtension.
* **Устранение черной дыры трафика ("сброс на нолики")**: Системный поток пакетов `utun` подключается напрямую к ядру Libbox, обеспечивая прозрачное проксирование трафика.
* **Внутренняя маршрутизация DNS**: Надежный резолвер через `dns-out`, изоляция приватных IP (Bypass LAN) и исключение утечек DNS.
* **Иконка приложения**: Премиальный темный стиль со светящейся эмблемой щита и молнии.
* **Нативный экран без рамок**: Полноэкранное отображение на всех моделях iPhone благодаря `LaunchScreen.storyboard`.
* **GeoIP определение нод**: Автоматическое определение страны и флага по IP-адресу сервера.
* **Мгновенный статус Dashboard**: Реактивное обновление состояния туннеля в реальном времени.

## Ключевые возможности

* **VLESS + Reality & Hysteria 2 / 1:** поддержка передовых протоколов обхода блокировок.
* **Полная поддержка подписок Happ:**
  * Запросы подписки отправляются с официальными заголовками:
    * `User-Agent: Happ/3.13.0 (...)`
    * `X-Hwid: <постоянный UUID>`
    * `X-Device-Os: iOS`
    * `X-Device-Model: iPhone12,3` (динамическое определение реальной модели устройства)
  * Поддерживаются схемы `happ://`, `vless://`, `hysteria2://`, `hy2://`, base64-списки и прямые JSON-конфигурации.
* **Постоянный HWID без слета:**
  * Уникальный идентификатор устройства сохраняется в защищенное хранилище **iOS Keychain** (`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`).
  * Он не меняется и не сбрасывается при закрытии, очистке памяти или переустановке приложения.
  * Доступен просмотр, копирование и ручной ввод HWID в меню Настроек.
* **Тройная защита подписок от потери:**
  * Атомарная запись в изолированную директорию приложения (`.atomic`).
  * Дублирование в App Group контейнер и резервный кэш `UserDefaults`.
  * Функция ручного экспорта и импорта полного JSON-бэкапа (в «Файлы» или мессенджеры).
* **Автоматическая сборка в GitHub Actions:**
  * Сборка чистого `.ipa` на macOS-раннере с автоматической публикацией GitHub Release.

## Установка через GBox / Scarlet / TrollStore / Esign

1. Скачайте `ffpp-unsigned.ipa` из вкладки [Releases](https://github.com/ffefl1n/ffpp/releases).
2. Импортируйте ваш сертификат разработчика (`.p12` и `.mobileprovision`) в GBox / Scarlet / Esign.
3. При подписании **ОБЯЗАТЕЛЬНО** активируйте опцию:
   👉 **«Подписывать расширения / PlugIns» (Sign Extensions)**
4. Установите приложение на iPhone и разрешите добавление VPN-конфигурации при первом подключении.
